# 失败部署清理与回滚

## 安全清理本地构建残留

```powershell
.\Remove-Failed-Deployment.ps1 -Root $PWD -BuildArtifactsOnly
```

会删除：

- `build/pages-local`
- `build/registry-packages`
- `build/phylang-registry.exe`
- 其他 `build` 下的不完整产物

不会删除源码、包清单、锁文件、`.git` 或远程仓库。

## 清理部署脚本修改并恢复备份

```powershell
.\Remove-Failed-Deployment.ps1 -Root $PWD
```

除构建目录外，还会恢复 `.phylang-deployment-backup` 中保存的 `registry-hosting.json` 和 `.github/CODEOWNERS`。

## 删除本地 Git 元数据

这是破坏性操作，必须提供精确目录确认：

```powershell
.\Remove-Failed-Deployment.ps1 `
  -Root $PWD `
  -RemoveLocalGitRepository `
  -ConfirmLocalPath $PWD.Path
```

## 删除远程 GitHub 仓库

先授予 GitHub CLI 删除仓库权限：

```powershell
gh auth refresh -h github.com -s delete_repo
```

再执行双重确认：

```powershell
.\Remove-Failed-Deployment.ps1 `
  -Root $PWD `
  -Repository 'MuRongMoQing/phylang-registry' `
  -RemoveRemoteRepository `
  -ConfirmRepository 'MuRongMoQing/phylang-registry'
```

脚本不会在普通构建失败时自动删除远程仓库。
