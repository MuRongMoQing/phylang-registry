# 故障排查

## PowerShell ParserError 或中文乱码

本发行版 `.ps1` 使用 UTF-8 BOM 与 CRLF，且关键部署脚本源码只含 ASCII。先运行：

```powershell
.\scripts\windows\Test-PowerShellSyntax.ps1
```

## GitHub Actions `Permission denied`

工作流使用 `bash ./scripts/...`，同时 bootstrap 会执行 `git update-index --chmod=+x`。不要把工作流改回直接执行无权限脚本。

## `gh repo view` 在新仓库上终止脚本

0.6.2 使用独立的原生命令捕获函数，把“仓库不存在”作为正常分支处理；不要重新加入直接的 `gh repo view ... 2>$null` 探测。

## Pages 尚未可访问

完整性工作流会重试约五分钟。手工检查 Actions 中部署 Job 是否成功，并确认 Settings → Pages 的 Source 为 GitHub Actions。
